# 냥냥 AI센터 2.0 · GPT 웹앱 v1.0

## 사용
- GitHub Pages에 배포된 `https://nangfejange.github.io/nyang-center/`에 접속하면 바로 이용 가능합니다.
- 갤럭시 폴드: Chrome 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**.
- iPad: Safari 공유 → **홈 화면에 추가**.
- 처음 열면 14개 사무실이 생성되며, 빈 업무는 직접 등록할 수 있습니다.

## 현재 지원하는 기능
- 렉돌 대장 보라 / 저작권 독립적인 도트 고양이 보행 애니메이션 / 14개 기본 사무실 및 신규 사무실 추가
- 전체 업무 지시, 사무실 상세, 회의실 상태(미답변/진행중/접수/검수/완료/반응·의견/보류) 필터
- 각 미답변 카드에서 라디오 버튼으로 승인/수정 요청/보류 선택 및 1클릭 답변 저장
- 개선 요청 기록, 업무 내용/담당/상태 수정, 업무 내용 복사(외부 AI에 수동 전달)
- 새로고침, 같은 기기 내 저장, 다른 탭 상태 반영, JSON 백업·복원, 연결 상태 점검
- PWA 홈 화면 설치, HTTPS 오프라인 캐시, 반응형 PC·폴드 화면

## 중요: 아직 연결되지 않은 것
이 버전은 **기기별 독립 업무판**입니다. AI 자동 협업/스레드 답변 전달, 피클 2명, Claude Code 원본 업무 이관, Google Drive/GitHub 동기화, 여러 기기 간 실시간 공유는 아직 연동되지 않았습니다.
웹 주소가 같아도 기기마다 저장된 데이터는 다릅니다. 중요한 업무는 **백업** 버튼으로 안전하게 저장하세요. 개인 고객 실명, 병력, 인증정보, API 키 등 민감정보 입력 금지. 이 웹앱의 소스 코드는 공개 정적 웹호스팅에 게시되나, 브라우저에 입력한 업무 데이터는 서버로 전송하지 않습니다.

## 개발 파일
- `index.html`: 웹페이지
- `styles.css`: 스타일 및 반응형 레이아웃
- `app.js`: 업무 로직과 도트 고양이 SVG
- `manifest.webmanifest` 및 `icon-*.png`: PWA 메타데이터
- `sw.js`: HTTPS 오프라인 캐시
